# Learning Practice

面向秋招准备的本地学习工具：飞书管理原始题库，本地保存每日任务、作答、面试和复习记录。

## 功能

- 可调整每日代码与八股题量，按嵌套模块分配练习。
- 今日学习与自由练习恢复当天确认的同一题单和进度；次日按已确认设置更新本地随机题。模型选题和变种题仍需手动点击。秋招入口不自动展示旧会话；具体会话保留对话。
- 方向面试、错题深挖与经典题入口；追问可整理、修改并确认加入复习。
- 每日练习与自由练习分别统计热力图，支持个人复盘和模型错题复盘。
- 自由练习按代码／八股独立抽原题，或由模型基于原题生成有来源记录的变种题。
- 秋招支持自选方向或随机推荐方向，再由模型提问。
- 手动重新对齐飞书，记录变更并保护历史版本。
- 页面请求超时恢复，恢复旧提交时保留之后补写的草稿；复习库保留代码／八股分类和逐题版本、学习记录。独立历史模块已移除，旧地址跳转复习库。
- 各环节独立配置 Agnes 模型与提示词，已有请求继续保留生成时的配置快照。

自由练习首次进入先选择并确认出题；此前遗留的题单和失败提示不自动展示。确认后的题单当天重开继续恢复；次日自动抽本地原题只沿用已确认的设置。

题库待整理内容支持分页并显示真实总数。按描述选题会按预算分批检查完整候选池，失败后恢复原请求；长参考资料保留全文，超过单次预算时明确提示原因。自由练习足迹显示的是近半年统计。

## 日常使用（Windows）

- 在项目目录双击 **`打开学习练习.cmd`**：自动启动后台服务并打开网页；已经运行时直接打开。
- 用完关闭网页即可，日常无需手动停止。关机或重启会结束服务，下次仍双击同一个入口，不需要打开 Codex。
- 固定地址：`http://127.0.0.1:8000/`。完整使用说明在项目 [README.html](README.html#daily-use) 中。
- 更新程序后的重启方法放在说明页的维护部分。启动错误日志在 `.runtime/server-8000-error.log`。

## 首次安装

需要 Python 3.12 和 uv。在项目目录执行：

```powershell
uv sync --dev
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

在本机 `.env` 填写 `AGNES_API_KEY`。已有 `.env` 时不要覆盖。读取飞书需要另行安装、登录和授权 `lark-cli`。

```powershell
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

打开 <http://127.0.0.1:8000/>。

## 数据与配置

运行数据默认保存在 `data/`，可通过 `LEARNING_DATA_DIR` 调整。应用日期默认使用 `Asia/Shanghai`，可通过 `LEARNING_TIMEZONE` 指定其他 IANA 时区；初始化题源文件可通过 `LEARNING_SOURCE_CONFIG` 指定。相对路径统一从项目根目录解析，不再依赖启动命令所在目录。

Agnes 的默认端点和默认模型支持通过 `AGNES_BASE_URL`、`AGNES_MODEL` 覆盖；每个业务模块仍可在“设置与备份”中单独选择 Agnes 模型。完整示例见 `.env.example`。仓库不包含本机密钥、数据库、媒体归档、学习记录或备份；换电脑使用时，需要单独迁移数据并配置飞书访问权限。

公开仓库不含个人飞书链接；首次运行后，在“题库与来源”登记自己的来源。已有本地数据库中的来源保持不变，可选初始配置文件 `local-config.sources.json` 也被Git忽略。测试与演示中的题源标识均为占位示例。

模型服务可能超时，部分模糊题源仍需确认；完整的候选多题拆分编辑器尚未实现。
