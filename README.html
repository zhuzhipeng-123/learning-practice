Learning Practice

本地学习、练习与复习工具。飞书保存原始题目和参考资料，SQLite 保存任务、作答、评价和复习记录。

目前可以做什么

自由练习可选题库原题或模型变种题；变种保留原题版本与生成记录，不写入飞书原题池。每日练习和自由练习各有学习足迹，只有提交才计数，点击日期可分开查看。

学习足迹和今日复盘位于首页最上方；代码与八股分区展示，首次进入先保存题量才展示题单，返回已保存的练习可继续；首页题单对应保存后的代码／八股数量；修改未保存时会提示，首页不展示额外练习，自由练习按代码与八股独立抽题，旧题可在折叠记录中继续。八股只从一级至三级标题识别题目，四级以下标题和正文属于参考内容。秋招支持自己填写方向或让模型随机推荐方向，再生成开场问题。

  • 读取飞书 Docx，按确认过的题目边界刷新内容。图片和嵌入表格按内容摘要归档，历史任务保留原版本。
  • 生成每日任务，继续跨日未完成任务；自由练习支持自然语言描述范围或完全随机，显示可点击的题目卡片，并报告数量不足。
  • 代码题自评会做／不会做；理论题先保存回答，再点击评价或重试，也可以手动更正评价。
  • 查看作答历史，显式加入复习库，从复习库开始练习。查看参考、历史答案或评价会记录答案暴露。
  • 保留题目版本、人工评价和学习事实，导出数据库与媒体，并在独立临时目录校验备份。

题目身份不明确时需要确认是已有题目的移动，还是独立新题。素材缺失的题目不能分配为新任务。网络或权限失败不会被当成删题。

安装和启动（Windows PowerShell）

需要 Python 3.12；已有 uv 时在项目目录运行：

uv sync --dev
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000

这台电脑已准备好项目虚拟环境，直接启动即可：

cd 'C:\projects\learning-practice'
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000

浏览器打开 本地学习页面。默认数据目录为 data/；用 LEARNING_DATA_DIR 指定其他目录。所有测试使用临时目录，不初始化正式学习库。

配置

公开仓库已移除个人飞书链接和本机路径。首次安装在“题库与来源”登记自己的来源；已有数据库保持原样。可选初始来源配置 local-config.sources.json 仅保存在本机，不提交到 Git。演示标识为占位值。

项目启动会读取被 Git 忽略的 .env，已有环境变量优先。参考 .env.example，按所用服务在本机填写 AGNES_API_KEY 或 OPENROUTER_API_KEY；不要把密钥放到代码、提交或报告中。

  • 飞书使用已安装的 lark-cli 和机器人身份；Windows npm 安装会解析到原生程序。也可设置 LARK_CLI_PATH。
  • 图片需要 docs:document.media:download，表格需要 sheets:spreadsheet:read，还需有目标文档的读取权限。
  • 真实模型评价需要配置所选服务的密钥；未配置时回答仍会保存，评价失败可重试。模型调用由页面操作触发；重新对齐飞书会在后台读取目录、原文和素材，并分析候选。平时没有定时同步。

各模块模型设置

进入应用的“模型设置”，分别编辑答案评价、面试追问、面试总结、每日反思、题目边界分析、按描述选题的服务、模型 ID、提示词与输出上限。每个模块独立保存，修改后刷新仍保留。

Agnes 使用 AGNES_API_KEY；OpenRouter 使用 OPENROUTER_API_KEY，接口固定为 https://openrouter.ai/api/v1/chat/completions。可以按官方模型列表填写带 :free 后缀的模型 ID；程序不会自动切到其他模型。OpenRouter 免费变体说明

切换到 OpenRouter 时默认填写 nex-agi/nex-n2.5-mini:free，各模块仍可分别修改。项目沿用 Python Chat Completions 接口，无需安装 JavaScript SDK。

已经发起的模型请求保留原提示词和模型配置，重试仍使用该快照；修改对新请求生效。程序会保留结果结构和证据校验要求。密钥不写进 SQLite，不随备份导出。

已完成的理论作答可点击“按当前设置重新评价”。程序保留原回答和历史评价；人工采用的结论不会被模型覆盖，同一作答不会重复增加任务或复习通过次数。请求失败后可按本次设置重试，刷新页面仍能找到最新请求。

遇到服务限流，会保存可重试时间并显示提示。同一数据库内各模块共享该服务的冷却时间；重新发起请求也需等待。服务未给出有效等待时间时默认等待 60 秒，到期后手动重试。模型返回截断标记时不会采用不完整结果。

独立模型请求可以同时运行，没有全局串行或固定六秒间隔。同一请求重复点击只执行一次；只有服务实际返回 429 才进入冷却。

手动对齐飞书与历史保护

首页和题库管理都有“重新对齐飞书”。每次点击重新遍历 Wiki 所有后代及分页，新增子文档自动登记；普通 Docx 链接仅同步该文档。入口以外的文档需单独登记。读取使用项目固定的应用身份，需要 wiki:node:retrieve 和文档读取权限。

对齐在后台运行，可刷新后继续查看进度。同一轮重复点击复用运行任务；本轮结束后再次点击，会重新检查最新内容。结果列出逐篇文档、新增/移动/缺失节点、新增题目、修改内容、缺失待核验、确认移除及模型建议。解析失败、目录权限失败、素材失败和模型失败分别显示，不用失败结果删除数据。

代码负责完整读取、锚点、版本与历史保护；Agnes 分批分析候选的单题、多解法、复合题、笔记和材料缺失。每批输出校验原文锚点，格式错误最多自动重试一次。建议不会直接覆盖历史或凭空补造题目；模糊边界和身份迁移仍需确认。

已经分配的任务继续引用原题版本；作答、人工评价和复习事实保留。完整读取发现原位置缺失时先暂停新抽题，独立完整读取两次并排除歧义后确认移除。未完整列出的目录不用于判断删文档。重建的块 ID 或跨文档搬题可能需要确认是否沿用原题。

首页模块与学习热力图

八股按“Wiki 文件夹 → 文档 → 正文标题”逐层展开，可为各分支填写随机题数。父、子分支不能同时分配。今天的题量可以增减，只重新安排未开始的题，已开始和完成的记录保留；没有可练习题的模块明确显示 0。

首页展示近半年的 GitHub 风格绿色小方格，每格可点入当天详情。按实际上海日期和主任务去重；同一任务一天多次作答或追问算一次活动。详情列出题目、模块、会/评价通过、不会/需复习、待评价和无法判断，并链接原作答及面试会话。查看页面不增加活动，也不会把提交次数当成掌握程度。

使用示例

  1. 点击“重新对齐飞书”，等待逐篇读取与模型分析完成；查看更改清单和待确认题目。第一次整库对齐可耗时数分钟，平时无需重复。
  2. 进入“今天”，逐层选择八股模块和题量并生成任务；数量不足时保留实际可分配数量，不自动补造题目。
  3. 进入一道题，保存回答或自评。理论题点击“开始评价 / 按原设置重试”；修改模型设置后可重新评价，需要时采用自己的评价。
  4. 从“复习库”开始新练习；同轮同一自然日最多记一次有效通过，累计至少 5 次且首末间隔严格超过 7 天才达标。失败不清零，撤销评价会重算。

按学生练习流程使用

  1. 在首页调整代码和八股数量，八股仅一个可展开入口；指定子模块后，其余数量随机。减少数量不移除已开始和完成的题。
  2. 自由练习可描述自己的范围，也可以完全随机。秋招支持填写练习方向或随机推荐方向，由模型生成开场问题，岗位和考察重点由自己填写。
  3. 首页开头展示学习足迹，并分别保存个人复盘和模型错题复盘。模型读取题目、备注和采用的评价；已有模型复盘需点击查看，以记录可能的答案暴露。
  4. 题库页先展示代码和八股模块及题量。在对齐说明框填写新增、删除、移动了哪些内容，再开始完整读取和模型核对。说明本身不能当成删题证据。

输出长度的依据

默认上限按用途设置，不是必须输出的长度。面试方向与开场1024、答案评价2048、面试追问1024、面试总结2048、错题复盘4096、对齐复核4096、按描述选题2048。变种题6144（每次最多3道，含参考解法）。高级设置默认折叠；提示词可独立修改。实际接入验证可能受模型服务状态影响，超时后不丢失作答、不自动更换服务。

首页每60秒及回到页面时检查本地日期。新一天会刷新干净页面；有未保存输入时保留输入并提示前往今天。热力图按真实提交日期更新，查看页面和生成模型文字不增加练习次数。
