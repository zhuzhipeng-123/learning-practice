日常怎么安排最省事？
  • 每天：打开“今天”，先看足迹，再确认题量；只在需要排除某份八股子文档时展开文档范围。练完后在页面最末保存个人复盘或生成模型复盘。新一天只预填上次确认的偏好，必须再次点击确认才会出题。
  • 想多练：进入“自由练习”，代码和八股各自设置。已确认的本地原题随机模式可在新一天沿用设置；模型变种题与按描述选题不会自动执行。
  • 核对参考：飞书来源笔记是学习参考，不等于逐项人工核验；模型生成参考也可能出错。重要结论请结合原始资料判断。
  • 不会的题：代码或八股都可选择“完全不清楚 / 模糊 / 一般”；明确不会无需调用模型，会保存这次学习并加入复习。模型评价不会偷偷修改你的掌握程度。
  • 准备面试：在“秋招”选择方向，回答后继续追问。模型有可能答错，关键参考结论仍需核对。
  • 改了飞书原题：到“题库与来源”点击对齐更新。平时打开网页不需要重新同步。
  • 定期或更新程序前：到“设置与备份”下载学习备份，再核验最近一次备份；将下载的 ZIP 另存一份。
打不开、报错或想更新程序时怎么办？
  • 网页打不开：先双击 打开学习练习.cmd，等待自动打开；不要重复安装环境。
  • 提示“代码已更新，需要重启”：先复制未提交的输入，等待正在保存的操作完成，在项目文件夹打开 PowerShell，执行下面的维护命令，然后双击“打开学习练习.cmd”。
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\service.ps1 -Action Stop
    日常练习无需执行此命令。
  • 启动窗口报错：窗口会停留，按提示查看 .runtime/server-8000-error.log。若提示端口被其他程序占用，启动器会保留该程序，不擅自关闭。
  • 模型失败：已保存的回答不会消失，使用页面中的恢复或重试按钮；不要反复点新建。模型评价、生成、追问需要联网和有效密钥，本地随机抽题不需要调用模型。
  • 维护重启前先保存正在写的回答；中断的模型任务下次会提示恢复。不要删除 data/ 或覆盖 .env，它们分别保存默认学习数据和本机配置。

自由练习与秋招面试

自由练习的代码和八股分别选择题源、抽题方式、描述与题量。两边可同时生成；离开或刷新后回来，进度和题单仍在。修改设置用于下一批，已有题目继续可练。原题只抽没提交过的题，也可选择生成变式；加练不会增加首页基础目标。秋招提供错题深挖、经典题和自选方向入口。经典题为空时会明确提示，并使用可练习的原题。

不会的主问题可直接加入复习。面试追问先整理成独立题目和参考要点，你可以修改并确认；只有核对参考后，才允许它用于自动评价。代码面试需明确自评，聊天不算独立复习通过。

飞书改题后，如何更新题库？

到“题库与来源”点击重新对齐飞书。平时使用本地题库，不会每次打开页面都访问飞书。Wiki 会遍历可读后代和分页，Docx 则读取该篇文档；失败、权限不足或分页不完整不会证明题目被删除。

已做过的任务保留原题版本与回答。复杂笔记、身份不明确、参考不完整的内容进入待整理；补全原文或确认边界后再同步。图片与表格按版本归档，但目前没有 OCR／视觉评价。

保存、计数和复习分别意味着什么？

保存表示这次作答留下来了，不代表回答正确。首页目标只算每日基础题；自由练习单独统计；学习活动仍记录每日、加练、复习与面试的已提交作答。同一主任务同一天多次作答或追问只算一次活动。

同轮复习每天最多一个有效通过，累计至少五次且首末间隔严格超过七天才退出；失败不清空已获得的通过。看每日复盘不会触发答案暴露；查看参考、历史答案或答案型面试总结会影响接下来 24 小时的有效通过。

新作答会让旧模型复盘提示需要更新，你可以重新生成；不会自动覆盖你的个人复盘。没有作答的日子，不会凭空出现学习足迹。

安装和启动

这台电脑已有环境，平时直接双击 打开学习练习.cmd。以下命令仅用于新电脑或首次安装，需要 Python 3.12 和 uv：

uv sync --dev
# 仅当本机还没有 .env 时创建
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000

这台电脑已有项目虚拟环境，也可直接运行：

.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000

在被 Git 忽略的 .env 中配置 AGNES_API_KEY，读取飞书需安装并授权 lark-cli，同时具有文档和相关素材的读取权限。首次使用在题库页登记自己的来源。

默认数据目录是 data/，默认学习日期使用 Asia/Shanghai。需要迁移时，可用 LEARNING_DATA_DIR、LEARNING_TIMEZONE 和 LEARNING_SOURCE_CONFIG 分别调整数据目录、IANA 时区和初始化题源文件；相对路径从项目根目录解析。

Agnes 模型端点和默认模型可用 AGNES_BASE_URL、AGNES_MODEL 调整，密钥仍只放在本机配置中。完整示例见 .env.example。不要把示例、测试数据放进正式学习库。详细迁移配置见 安装与迁移说明。

模型设置、失败恢复与数据备份

“模型与提示词”中各模块可独立设置 Agnes 模型和提示词。新问题配对保存参考答案，点击才显示；旧题可显式补充。局部来源校正按版本独立保存，不改写原题。旧请求保留当时配置，按当前设置重新评价会创建新的请求；人工采用的结果不会被迟到模型覆盖。

回答先保存，模型超时或格式错误后可以重试。页面等待有时间上限，连接挂起也会给出恢复提示；恢复旧提交时，之后补写的草稿单独保留，可复制另存。明确失败后可修改重试；仍在处理中或网络结果不确定时按页面恢复原请求。外部模型恢复时仍可能重复请求，但只有当前执行拥有者可以写入学习结果。评价与代码自评会更新页面状态；草稿属于当前浏览器，不跨设备共享。浏览器禁用存储时仍可保存正式回答，但不能保证刷新后的草稿恢复。

从“设置与备份”下载学习备份，再点击“核验最近一次备份”；包含数据库与媒体，核验在独立目录进行。SQLite 当前为 v16，旧库升级前自动备份。回退前先保存新数据，使用配套旧代码在独立目录核验，不要直接覆盖现在的学习记录。密钥不放进数据库或导出包。
